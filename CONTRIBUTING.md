# Contribuir

Comece pelo README e pelo AGENTS.md. Rode `npm test`, `npm run examples` e `npm run build`; para alterações no núcleo C++, rode o teste host e compile ESP32 conforme `firmware/README.md`. Use inglês em identificadores/comentários/documentação de engenharia e pt-BR nos guias e interface.

Registre hipótese, unidade SI, origem, método, resultado e limite. Não substitua UNKNOWN por palpite nem descreva simulação como medição. Relate a primeira falha de forma reproduzível. Não mude flags de atuação para fazer um teste passar. Alterações elétricas/mecânicas precisam de fonte, análise de risco e critérios de revisão; não anuncie liberação para fabricação com base apenas em CAD ou teste de software.

Antes de importar arquivos externos, confira licença e atribuição por componente, incluindo CAD, imagens e Gerbers. Não copie código GPL para este código original MIT por conveniência. Abra uma proposta que explique a dependência e sua licença. Não acrescente credenciais, logs pessoais ou publicidade de fornecedor sem fundamento.

Cotações: registre SKU, unidade, fonte individual, data, intervalo mínimo/máximo e estado. Busca do Mercado Livre não é oferta verificada. Fonte técnica do fabricante não confirma estoque/preço brasileiro. Preserve os campos de entrada e os checks da planilha.

Publicação externa, push, release, deploy ou associação institucional exige autorização pertinente. Revisão por outro membro é recomendada para alterações de intertravamentos, potência e máquina de estados.
