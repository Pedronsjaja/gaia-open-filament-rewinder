# Simulator and integration contract v1

SI internal units: m, s, kg, kg/m^3, rad, V, A, N, N m. User-facing mass grams converts at the boundary. Offline demonstration is the default and only enabled transport in this release. No UI command controls physical equipment. Live HTTP/WebSocket connection remains explicitly disabled until integration validation.

Root provides `software/simulator/math.mjs`: MATERIALS object PLA/PETG/ABS with `{label,densityKgM3,evidence}` (illustrative assumed densities, not measured); `massKg(lengthM,diameterM,densityKgM3)`, `lengthM(massKg,diameterM,densityKgM3)`, `metresPerCount(wheelDiameterM,countsPerRevolution,calibrationFactor=1)`, `calibrationFactor(referenceLengthM,observedCounts,wheelDiameterM,countsPerRevolution)`, `relativeMassUncertainty(lengthRelative,diameterRelative,densityRelative)`. Inputs reject NaN/infinite/nonpositive geometry/density/calibration; zero length/mass permitted.

Root provides `software/simulator/machine.mjs`: `new RewinderSimulator(config={})`, `.configure(patch)` only while IDLE/COMPLETED/STOPPED, `.start()`, `.pause()`, `.resume()`, `.stop()`, `.resetFault()` returns IDLE with no auto restart; `.injectFault(code)` fault latches and zeros speed; `.tick(dtSeconds)` updates demo using acceleration ramp and integer encoder counts; `.calibrate(referenceLengthM,observedCounts)` only when not active. `.snapshot()` returns JSON copy, `.history` array. User speeds m/s; defaults 0.1 m/s max 0.5, acceleration 0.1 m/s^2. FAULT and STOPPED do not move, pause decelerates logically by zeroing simulated motion (not a physical braking model).

config: `{material:'PLA',densityKgM3:1240,diameterM:0.00175,targetMode:'length'|'mass',targetLengthM:10,targetMassKg:0.025,speedMps:0.1,accelerationMps2:0.1,wheelDiameterM:0.03,countsPerRevolution:600,calibrationFactor:1}`. Counts mean effective decoded counts per measuring-wheel revolution, not arbitrary encoder datasheet PPR. UI converts mm, grams, mm/s to SI.

snapshot: `{schemaVersion:'1.0',mode:'SIMULATED',state:'IDLE'|'RUNNING'|'PAUSED'|'COMPLETED'|'STOPPED'|'FAULT',config,lengthM,massKg,targetLengthM,progressPercent,speedMps,elapsedS,encoderCounts,fault,alerts,sensors:{filamentPresent,movementDetected,leftLimit,rightLimit}}`. State has no claim of safety certification. History items contain outcome, simulated length/estimated mass/elapsed, config and mode. Firmware protocol uses same SI field semantics; firmware transport may be a polling HTTP snapshot, with WebSocket documented as future if not implemented. Protocol remains versioned and commands require local firmware interlocks.
